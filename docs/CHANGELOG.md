# Changelog

## [2.0.0] - 2025-01-28

### Added
- WiFi password grabber module
- Active window tracker
- Module scheduler with configurable intervals
- Telegram reporting option
- Process hiding via attribute manipulation
- Data aggregator for compressed reports

### Changed
- Migrated to .NET 9.0
- Refactored module architecture for plug-and-play
- Improved keylogger with dead key handling

## [1.5.0] - 2024-09-20

### Added
- Microphone recording module
- Browser history collector (Chrome, Firefox, Edge)
- Service-based persistence option
- Email reporting with SSL/TLS

### Fixed
- Screenshot quality on high-DPI displays
- Webcam device enumeration crash

## [1.0.0] - 2024-05-10

### Added
- Initial release
- Keylogger with window context
- Periodic screen capture
- Webcam snapshot
- Clipboard watcher
- Registry persistence
- Email delivery
